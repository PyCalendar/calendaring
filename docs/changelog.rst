==========
Change log
==========

Every calendaring release, newest first. Entries are collected from the
fragments in ``news/`` by `towncrier <https://towncrier.readthedocs.io/>`_
at release time; see ``CONTRIBUTING.md``.

.. towncrier release notes start

0.1.0 (2026-10-31)
------------------

0.1.0 is the first release.  The CHANGELOG should be the place to look for "what has changed since the last version?".  The CHANGELOG for v0.1.0 is intentionally left blank since there does not exist any "last version" to compare with (alternatively, we could let the CHANGELOG list all the features of the library, but that's better described in other documentation).
