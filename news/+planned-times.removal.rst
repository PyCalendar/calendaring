``Task.planned_start``, ``Task.planned_end`` and the ``task.planned`` capability are gone, and ``X-PYCAL-PLANNED-START`` and ``X-PYCAL-PLANNED-END`` are no longer mapped to a capability.  No calendar client reads a planned start or end on a task; time planned for a task belongs in an event linked to it with ``RELATED-TO``, which every client shows.  A task that already carries the properties keeps them as ordinary X- properties.
