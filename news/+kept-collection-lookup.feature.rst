The conformance suite lists a backend's collections at most once a session for each name it uses to find the collection a test or run kept, and only once where a previous run left them all, where it used to in every test: about 4.5 minutes each on an account with 469 calendars.  It then opens the kept one again through a new hook, ``reopen()``, which looks it up by id; the CalDAV tests override it to open the calendar from its URL.
