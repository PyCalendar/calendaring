``create_collection()`` refuses to make a collection that would hold none of the requested components, raising ``UnsupportedError``.  Where a server ignores the requested components, as SOGo does, the ``create-collection`` capability says so (``LOSSY``), and the collection's ``components`` say what it actually holds.  Where each collection holds one kind only, as on CCS or in a task tracker, the new ``collection.mixed`` capability says so, ``create_collection()`` makes the collection for one of the kinds asked, and the conformance suite tests each kind in a collection of its own.
